1 · Transformaciones geométricas

Modifican la forma, orientación o tamaño del emoji. Usan transform.

☐1.1 · Flip horizontalscaleX(-1)
➡️

Qué hace: espeja el emoji de izquierda a derecha.

Fórmula: transform: scaleX(-1);

Uso: dirección del jugador, mobs, flechas.

.flip-h { transform: scaleX(-1); }
☐1.2 · Flip verticalscaleY(-1)
🔥

Qué hace: espeja de arriba a abajo.

Fórmula: transform: scaleY(-1);

Uso: fuego animado, flechas ↑↓, hojas 🍃.

.flip-v { transform: scaleY(-1); }
☐1.3 · Rotación 45°rotate(45deg)
➡️

Qué hace: gira 45° en sentido horario.

Fórmula: transform: rotate(45deg);

Uso: flechas NE, cohetes, objetos rotados.

.rot-45 { transform: rotate(45deg); }
☐1.4 · Rotación 90°rotate(90deg)
➡️

Qué hace: gira 90° (apunta hacia abajo).

Fórmula: transform: rotate(90deg);

Uso: flechas, tuberías, vigas.

.rot-90 { transform: rotate(90deg); }
☐1.5 · Rotación 135°rotate(135deg)
➡️

Qué hace: gira 135° (diagonal SO).

Fórmula: transform: rotate(135deg);

Uso: flechas SO, cohetes invertidos.

.rot-135 { transform: rotate(135deg); }
☐1.6 · Rotación animada (hover)transition + rotate
🧭

Qué hace: al pasar el mouse, gira 360° suavemente.

Uso: reloj, brújula, engranaje interactivo.

.rot-animada {
  transition: transform 0.8s ease-in-out;
}
.rot-animada:hover {
  transform: rotate(360deg);
}
☐1.7 · Escala 2×scale(2)
🐯

Qué hace: duplica el tamaño.

Uso: mobs grandes, jefes, objetos destacados.

.escala-2 { transform: scale(2); }
☐1.8 · Espejo diagonalscale(-1,1) + rotate
➡️

Qué hace: espejo horizontal + rotación 45°.

Uso: efectos ópticos, simetrías.

.espejo-diag {
  transform: scale(-1, 1) rotate(45deg);
}

9 · Fórmulas y reglas generales

Reglas para combinar efectos sin pisarse.

☐9.1 · Regla "un canal por propiedad"evitar conflictos

Regla: solo una declaración por "canal".

Canales: transform, animation, filter, text-shadow, background.

/* ❌ MAL: dos transforms, uno pisa al otro */
.a { transform: scaleX(-1); }
.b { transform: rotate(45deg); }

/* ✅ BIEN: un solo transform con todo */
.c { transform: scaleX(-1) rotate(45deg); }

/* ❌ MAL: dos animations */
.a { animation: pulse 1s infinite; }
.b { animation: spin 2s infinite; }

/* ✅ BIEN: una sola keyframes */
@keyframes pulseSpin {
  0%, 100% { transform: scale(1)    rotate(0deg); }
  50%      { transform: scale(1.18) rotate(180deg); }
}
☐9.2 · Fórmula: fondo temático3 capas

1. background → color dominante

2. background-image → 1-3 radial-gradient()

3. background-size → tamaños distintos

4. filter en el emoji → hue-rotate + brightness + saturate

.fondo-tematico {
  background: #COLOR_BASE;
  background-image:
    radial-gradient(circle at 25% 35%, #PUNTO 1.2px, transparent 1.2px),
    radial-gradient(circle at 75% 65%, #PUNTO 1.2px, transparent 1.2px),
    radial-gradient(circle at 50% 90%, #PUNTO 1px,   transparent 1px);
  background-size: 10px 10px, 14px 14px, 8px 8px;
}
.emoji-del-fondo {

☐9.4 · Qué se combina y qué noreferencia

✅ Se combinan bien:

• glow + sombra + parpadeo (canales distintos)

• rotación + escala → rotate(45deg) scale(1.5)

• animación + filtro → animation: pulse + filter: hue-rotate()

⚠️ Se pisan:

• Dos transform distintos

• Dos animation (salvo con comas)

• transform estático + animation con transform
