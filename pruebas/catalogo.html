1 · Transformaciones geométricas

Modifican la forma, orientación o tamaño del emoji sin cambiar su contenido. Todas usan la propiedad transform.

☐ 1.1 · Flip horizontal scaleX(-1)
➡️

Qué hace: espeja el emoji de izquierda a derecha.

Fórmula: transform: scaleX(-1);

Uso: cambiar la dirección del jugador, mobs, flechas.

.flip-h { transform: scaleX(-1); }
☐ 1.2 · Flip vertical scaleY(-1)
🔥

Qué hace: espeja el emoji de arriba a abajo.

Fórmula: transform: scaleY(-1);

Uso: fuego animado, flechas ↑↓, hojas 🍃.

.flip-v { transform: scaleY(-1); }
☐ 1.3 · Rotación 45° rotate(45deg)
➡️

Qué hace: gira el emoji 45° en sentido horario.

Fórmula: transform: rotate(45deg);

Uso: flechas a NE, cohetes en diagonal, objetos rotados.

.rot-45 { transform: rotate(45deg); }
☐ 1.4 · Rotación 90° rotate(90deg)
➡️

Qué hace: gira el emoji 90° (apunta hacia abajo).

Fórmula: transform: rotate(90deg);

Uso: flechas direccionales, tuberías, vigas.

.rot-90 { transform: rotate(90deg); }
☐ 1.5 · Rotación 135° rotate(135deg)
➡️

Qué hace: gira el emoji 135° (diagonal SO).

Fórmula: transform: rotate(135deg);

Uso: flechas SO, cohetes invertidos.

.rot-135 { transform: rotate(135deg); }
☐ 1.6 · Rotación animada (hover) transition + rotate
🧭

Qué hace: al pasar el mouse, el emoji gira 360° suavemente.

Fórmula: transition: transform 0.8s; + :hover { rotate(360deg); }

Uso: reloj, brújula, engranaje interactivo.

.rot-animada {
  transition: transform 0.8s ease-in-out;
}
.rot-animada:hover {
  transform: rotate(360deg);
}
☐ 1.7 · Escala 2× scale(2)
🐯

Qué hace: duplica el tamaño del emoji.

Fórmula: transform: scale(2);

Uso: mobs grandes, jefes, objetos destacados.

.escala-2 { transform: scale(2); }
☐ 1.8 · Espejo diagonal scale(-1,1) + rotate
➡️

Qué hace: combina espejo horizontal + rotación 45°. Efecto óptico.

Fórmula: transform: scale(-1, 1) rotate(45deg);

Uso: efectos visuales inusuales, simetrías.

.espejo-diag {
  transform: scale(-1, 1) rotate(45deg);
}

3 · Efectos visuales

Añaden brillo, profundidad o movimiento continuo. Usan text-shadow, filter y animation.

☐ 3.1 · Glow (halo) text-shadow
🔑

Qué hace: añade un resplandor alrededor del emoji.

Fórmula: text-shadow: 0 0 Npx color; (se pueden apilar varios).

Uso: ítems importantes, llaves, objetos mágicos, identidad visual.

.glow {
  text-shadow:
    0 0 8px cyan,
    0 0 16px rgba(0, 255, 255, 0.5);
}
☐ 3.2 · Sombra proyectada drop-shadow
🗿

Qué hace: genera una sombra detrás del emoji, dándole profundidad.

Fórmula: filter: drop-shadow(Xpx Ypx blur color);

Uso: objetos en relieve, rocas, estructuras.

.sombra {
  filter:
    drop-shadow(3px 3px 3px black)
    drop-shadow(0 0 6px rgba(0, 0, 0, 0.8));
}
☐ 3.3 · Parpadeo animation: parpadeo
💡

Qué hace: la opacidad baja y sube cíclicamente.

Fórmula: @keyframes parpadeo { 0%,100% { opacity:1 } 50% { opacity:0.15 } }

Uso: objetos brillantes, daño recibido, luces intermitentes.

@keyframes parpadeo {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.15; }
}
.parpadeo { animation: parpadeo 0.8s infinite; }
☐ 3.4 · Vibración animation: shake
👾

Qué hace: el emoji se sacude con traslación + rotación leve.

Fórmula: @keyframes shake con translate() y rotate() alternados.

Uso: combate, mobs "vivos", objetos temblando.

@keyframes shake {
  0%, 100% { transform: translate(0, 0) rotate(0deg); }
  20%      { transform: translate(-2px, 1px) rotate(-3deg); }
  40%      { transform: translate(2px, -1px) rotate(3deg); }
  60%      { transform: translate(-1px, 2px) rotate(-2deg); }
  80%      { transform: translate(1px, -2px) rotate(2deg); }
}
.vibracion { animation: shake 0.35s infinite; }
☐ 3.5 · Latido (pulse) animation: pulse
❤️

Qué hace: el emoji crece y decrece rítmicamente.

Fórmula: @keyframes pulse { 0%,100% { scale(1) } 50% { scale(1.18) } }

Uso: corazones, recuperación, objetos vivos.

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.18); }
}
.latido { animation: pulse 0.9s ease-in-out infinite; }
☐ 3.6 · Rotación continua animation: spin
🌀

Qué hace: el emoji gira constantemente 360°.

Fórmula: @keyframes spin { from { rotate(0) } to { rotate(360deg) } }

Uso: portales, energía, engranajes, tornados.

@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
.spin { animation: spin 2s linear infinite; }

4 · Técnicas de animación de tiles

Animaciones cíclicas cortas para simular "tiles animados": fuego, hojas, mundos girando, cadenas oscilando.

☐ 4.1 · Flip alternado scaleX ↔ scaleX(-1)
🔥

Qué hace: el emoji se voltea horizontalmente una y otra vez.

Fórmula: @keyframes flipAlternado con scaleX(1) ↔ scaleX(-1).

Uso: fuego, hojas, banderas, llamas vivas.

@keyframes flipAlternado {
  0%, 100% { transform: scaleX(1); }
  50%      { transform: scaleX(-1); }
}
.flip-alt { animation: flipAlternado 0.5s infinite; }
☐ 4.2 · Secuencia de emojis JS + setInterval
🌍

Qué hace: cicla entre varios emojis de un array.

Fórmula: array + setInterval + actualizar textContent.

Uso: 🌍🌎🌏 mundo girando, 🌑🌒🌓🌔🌕🌖🌗🌘 fases lunares, cometa.

const mundos = ['🌍', '🌎', '🌏'];
let idx = 0;
setInterval(() => {
  idx = (idx + 1) % mundos.length;
  document.getElementById('sec-mundo').textContent = mundos[idx];
}, 400);
☐ 4.3 · Rotación alternada rotate(0) ↔ 180
⛓️

Qué hace: gira 180° y vuelve a 0° cíclicamente.

Fórmula: @keyframes rotAlternada con rotate(0) ↔ rotate(180deg).

Uso: cadenas, relojes, péndulos.

@keyframes rotAlternada {
  0%, 100% { transform: rotate(0deg); }
  50%      { transform: rotate(180deg); }
}
.rot-alt { animation: rotAlternada 0.7s infinite; }
☐ 4.4 · Cambio de opacidad opacity 1 ↔ 0.35
🔥

Qué hace: el emoji aparece y desaparece parcialmente.

Fórmula: @keyframes opacidadAlt con opacity: 1 ↔ 0.35.

Uso: antorchas, faros, luces titilando.

@keyframes opacidadAlt {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.35; }
}
.opacidad-alt { animation: opacidadAlt 1s infinite; }
☐ 4.5 · Cambio de escala (respiración) scale 1 ↔ 1.25
💓

Qué hace: el emoji crece y decrece suavemente.

Fórmula: @keyframes escalaAlt con scale(1) ↔ scale(1.25).

Uso: respiración, latido suave, objetos pulsantes.

@keyframes escalaAlt {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.25); }
}
.escala-alt { animation: escalaAlt 1.1s ease-in-out infinite; }
☐ 4.6 · Cambio de color (hue-rotate) hue-rotate 0 ↔ 180
🔮

Qué hace: rota el tono de color del emoji cíclicamente.

Fórmula: @keyframes hueAlt con filter: hue-rotate(0) ↔ hue-rotate(180deg).

Uso: cristales, energía, objetos mágicos cambiando de color.

@keyframes hueAlt {
  0%, 100% { filter: hue-rotate(0deg); }
  50%      { filter: hue-rotate(180deg); }
}
.hue-alt { animation: hueAlt 1.5s infinite; }

5 · Combinaciones de efectos

Efectos apilados en una sola @keyframes o en propiedades distintas. Cada combinación simula un objeto concreto.

☐ 5.1 · Fuego encendido pulse + opacidad
🔥

Qué hace: cambio de escala (latido) + cambio de opacidad en una sola animación.

Simula: un fuego vivo que respira y titila.

Fórmula: @keyframes que anima transform: scale() y opacity a la vez.

@keyframes fuegoVivo {
  0%, 100% { transform: scale(1);   opacity: 1; }
  50%      { transform: scale(1.2); opacity: 0.65; }
}
.combo-fuego {
  animation: fuegoVivo 0.6s ease-in-out infinite;
}
☐ 5.2 · Portal encendido glow + spin
🌀

Qué hace: glow (text-shadow) + rotación continua (animation).

Simula: un portal mágico que gira y brilla.

Fórmula: animation: spin + text-shadow (propiedades distintas, sin conflicto).

.combo-portal {
  animation: spin 2.5s linear infinite;
  text-shadow:
    0 0 10px cyan,
    0 0 22px rgba(0, 255, 255, 0.7);
}
☐ 5.3 · Cohete en diagonal vibración + rotate(45°)
🚀

Qué hace: vibración (traducción) con rotación 45° fija en cada frame.

Simula: un cohete volando hacia el noreste.

Fórmula: en cada keyframe combinamos rotate(45deg) + translate(...).

@keyframes coheteVuela {
  0%, 100% { transform: rotate(45deg) translate(0, 0); }
  25%      { transform: rotate(45deg) translate(-2px, 1px); }
  50%      { transform: rotate(45deg) translate(2px, -1px); }
  75%      { transform: rotate(45deg) translate(-1px, 2px); }
}
.combo-cohete { animation: coheteVuela 0.4s infinite; }
☐ 5.4 · Cohete alternando dirección vibración + rotación variable
🚀

Qué hace: la vibración es más amplia y alterna el eje, simulando zigzag.

Simula: un cohete zigzagueando en diagonal.

Fórmula: igual que 5.3 pero con desplazamientos más grandes en X.

@keyframes coheteAlterna {
  0%, 100% { transform: rotate(45deg) translate(0, 0); }
  25%      { transform: rotate(45deg) translate(-3px, 1px); }
  50%      { transform: rotate(45deg) translate(3px, -1px); }
  75%      { transform: rotate(45deg) translate(-2px, 2px); }
}
.combo-cohete-alt { animation: coheteAlterna 0.4s infinite; }
☐ 5.5 · Cohete espejado (hacia NO) vibración + flip + rotate
🚀

Qué hace: combinación de flip horizontal + rotación -45° + vibración.

Simula: un cohete yendo hacia el noroeste (espejado).

Fórmula: se antepone scaleX(-1) a toda la cadena de transformaciones.

@keyframes coheteAlternaFlip {
  0%, 100% { transform: rotate(-45deg) scaleX(-1) translate(0, 0); }
  25%      { transform: rotate(-45deg) scaleX(-1) translate(-3px, 1px); }
  50%      { transform: rotate(-45deg) scaleX(-1) translate(3px, -1px); }
  75%      { transform: rotate(-45deg) scaleX(-1) translate(-2px, 2px); }
}
.combo-cohete-alt-b { animation: coheteAlternaFlip 0.4s infinite; }
☐ 5.6 · Nave alienígena (flotando) vibración suave (flotar)
🛸

Qué hace: traslación vertical suave hacia arriba y abajo.

Simula: una nave alienígena flotando en el aire.

Fórmula: @keyframes flotar con translateY entre 0 y -4px.

Fórmula: @keyframes con scale() + translateY() simultáneos.

7 · Cadena animada entre bloques

Simula una cadena (⛓️) que se mueve entre dos bloques fijos (🔲) que representan entrada y salida.

☐ 7.1 · Cadena sube/baja entre bloques flip alternado con fase
🔲
⛓️ ⛓️ ⛓️
🔲

Qué hace: 3 eslabones ⛓️ entre dos bloques 🔲. Cada eslabón alterna su orientación con una fase distinta.

Simula: cadena que sube y baja entre dos puntos (entrada/salida).

Fórmula: setInterval + scaleX(-1) alternado según (frame + fase) % 2.

.eslabon {
  font-size: 32px;
  transition: transform 0.08s linear;
}

// JS
let frame = 0;
setInterval(() => {
  frame++;
  document.querySelectorAll('.eslabon').forEach((el, i) => {
    const fase = (i % 2 === 0) ? 0 : 1;
    const voltear = ((frame + fase) % 2 === 0);
    el.style.transform = voltear ? 'scaleX(-1)' : 'scaleX(1)';
  });
}, 250);

9 · Fórmulas y reglas generales

Reglas para combinar efectos sin pisarse. Sirve como referencia rápida al diseñar nuevos tiles.

☐ 9.1 · Regla de "un canal por propiedad" evitar conflictos

Regla: solo una declaración por "canal". Si querés combinar, meté todo dentro de la misma propiedad.

Canales: transform, animation, filter, text-shadow, background.

/* ❌ MAL: dos transforms, uno pisa al otro */
.a { transform: scaleX(-1); }
.b { transform: rotate(45deg); }

/* ✅ BIEN: un solo transform con todo */
.c { transform: scaleX(-1) rotate(45deg); }

/* ❌ MAL: dos animations, solo vale la última */
.a { animation: pulse 1s infinite; }
.b { animation: spin 2s infinite; }

/* ✅ BIEN: una sola keyframes que haga ambos */
@keyframes pulseSpin {
  0%, 100% { transform: scale(1)    rotate(0deg); }
  50%      { transform: scale(1.18) rotate(180deg); }
}
☐ 9.2 · Fórmula: fondo temático con textura 3 capas

Fórmula general:

1. background → color dominante

2. background-image → 1-3 radial-gradient() repetidos = textura

3. background-size → tamaños distintos por capa (evita patrón obvio)

4. filter en el emoji → hue-rotate + brightness + saturate para integrarlo

.fondo-tematico {
  background: #COLOR_BASE;
  background-image:
    radial-gradient(circle at 25% 35%, #PUNTO 1.2px, transparent 1.2px),
    radial-gradient(circle at 75% 65%, #PUNTO 1.2px, transparent 1.2px),

☐ 9.4 · Qué se combina bien y qué no referencia

✅ Se combinan bien (canales distintos):

• glow (text-shadow) + sombra (filter) + parpadeo (animation)

• rotación + escala → dentro del mismo transform: rotate(45deg) scale(1.5)

• flip + escala → scaleX(-1) scale(1.5)

• animación + transición → una anima, la otra responde al hover

• animación + filtro → animation: pulse + filter: hue-rotate()

⚠️ Se pisan (mismo canal):

• Dos transform distintos → solo vale el último

• Dos animation → solo vale la última (salvo comas)

• transform estático + animation con transform → la animación gana mientras corre

🔑 Solución: unificar todo dentro de una sola declaración.

11 · Animaciones de tiles (flip + secuencia)

Dos categorías de animación de tiles: mismo emoji alternando orientación (flip) y varios emojis en secuencia. El loop global es compartido para todos los tiles.

☐ 11.1 · Mismo emoji, orientación alternada (flip) scaleX ↔ scaleX(-1)

Qué hace: en cada frame, el emoji se voltea horizontalmente una y otra vez.

Fórmula: (frame % 2 === 0) ? scaleX(1) : scaleX(-1) aplicado por JS.

Uso: fuego, huellas, portales, tornados, cadenas, orbes.
